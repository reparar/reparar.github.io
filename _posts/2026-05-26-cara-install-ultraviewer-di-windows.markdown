📌 **Cara install UltraViewer di Windows** langkah demi langkah:

Jika nyaman via Video, ke link ini: [https://youtu.be/tEJ9J8k17xs](https://youtu.be/tEJ9J8k17xs)

Jika nyaman dengan teks, ikuti panduan ini:

---

## ✅ Langkah 1: Download UltraViewer

- Buka browser seperti **Chrome**, **Edge**, **Opera** atau **Firefox**.

![Microsoft Edge]({{ site.baseurl }}/assets/images/ultraviewer/browser-edge.png)
![Google Chrome]({{ site.baseurl }}/assets/images/ultraviewer/browser-chrome.png)
![Firefox]({{ site.baseurl }}/assets/images/ultraviewer/browser-firefox.png)
![Opera]({{ site.baseurl }}/assets/images/ultraviewer/browser-opera.png)

**Bisa ketik ultra viewer di search bar, lalu Enter**

![Ketik ultra viewer di search bar]({{ site.baseurl }}/assets/images/ultraviewer/search-ultraviewer-bar.png)

![Tekan Enter untuk search]({{ site.baseurl }}/assets/images/ultraviewer/search-ultraviewer-enter.png)

![Hasil pencarian — klik Download]({{ site.baseurl }}/assets/images/ultraviewer/search-result-download.png)

**Klik Download**

- Klik tombol **Download** (Orange/kuning).

![Halaman download UltraViewer]({{ site.baseurl }}/assets/images/ultraviewer/ultraviewer-download-page.png)

- File installer (UltraViewer_setup.exe) akan mulai diunduh.

![Download sedang berjalan]({{ site.baseurl }}/assets/images/ultraviewer/download-progress.png)

---

## ✅ Langkah 2: Jalankan Installer

- Setelah unduhan selesai, klik show in folder atau bisa langsung open jika mau

![Show in folder]({{ site.baseurl }}/assets/images/ultraviewer/show-in-folder.png)

- **klik dua kali** pada file UltraViewer_setup.exe.

![File UltraViewer_setup.exe di folder]({{ site.baseurl }}/assets/images/ultraviewer/file-explorer-exe.png)

- Jika muncul jendela konfirmasi *User Account Control (UAC)*, klik **Yes** atau **Ya**.

---

## ✅ Langkah 3: Proses Instalasi

- Pilih lokasi instalasi atau biarkan default, lalu klik **Next**.

![Setup — pilih lokasi instalasi]({{ site.baseurl }}/assets/images/ultraviewer/setup-destination.png)

- klik **Next**.

![Setup — pilih Start Menu folder]({{ site.baseurl }}/assets/images/ultraviewer/setup-startmenu.png)

- klik **Next**.

![Setup — additional tasks]({{ site.baseurl }}/assets/images/ultraviewer/setup-additional-tasks.png)

- Klik **Install**.

![Setup — ready to install]({{ site.baseurl }}/assets/images/ultraviewer/setup-ready-install.png)

- Tunggu proses instalasi selesai.

![Proses instalasi berjalan]({{ site.baseurl }}/assets/images/ultraviewer/setup-installing.png)

- Setelah selesai, centang "Launch UltraViewer", lalu klik **Finish**.

![Setup selesai — klik Finish]({{ site.baseurl }}/assets/images/ultraviewer/setup-finish.png)

---

## ✅ Langkah 4: Mulai Menggunakan

- UltraViewer akan terbuka secara otomatis.

- Kamu akan melihat **Your ID** dan **Password** – ini yang kamu berikan ke seller untuk dibantu installasi produk yang dipesan.

- Kirim **Your ID** dan **Password** (Bisa di foto atau bisa di salin) **Kirim di chat shopee**

![Tampilan utama UltraViewer — Your ID dan Password]({{ site.baseurl }}/assets/images/ultraviewer/ultraviewer-main-window.png)
