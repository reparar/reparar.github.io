## Langkah 1: Download UltraViewer

- Buka browser seperti Chrome, Edge, Opera, atau Firefox.
- Ketik **ultra viewer** di search bar, lalu Enter.
- Masuk ke situs resminya, lalu klik tombol **Download** (warna orange/kuning).
- File installer `UltraViewer_setup.exe` akan mulai diunduh.

## Langkah 2: Jalankan Installer

- Setelah unduhan selesai, klik **Show in folder** atau langsung **Open**.
- Klik dua kali pada file `UltraViewer_setup.exe`.
- Jika muncul jendela konfirmasi **User Account Control (UAC)**, klik **Yes** / **Ya**.

## Langkah 3: Proses Instalasi

- Pilih lokasi instalasi atau biarkan default, lalu klik **Next**.
- Klik **Next** beberapa kali hingga tombol **Install** muncul.
- Klik **Install** dan tunggu proses selesai.
- Setelah selesai, centang **"Launch UltraViewer"**, lalu klik **Finish**.

## Langkah 4: Mulai Menggunakan

- UltraViewer akan terbuka secara otomatis.
- Kamu akan melihat **Your ID** dan **Password** — ini yang diberikan ke seller untuk dibantu proses instalasi produk yang dipesan.
- Kirim **Your ID** dan **Password** (bisa difoto atau disalin) via **chat Shopee**.
